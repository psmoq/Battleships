# Flappy

Prosta gra 2D w stylu Flappy Bird: jeden plik `index.html`, canvas, bez zależności i bez budowania. Dotknij ekranu (lub Spacja), aby podskoczyć.

## Uruchomienie

- **Codespaces (z telefonu, z dowolnego miejsca):** otwórz repo w Codespaces. Serwer startuje sam, a port 8080 jest przekierowany na adres `*.app.github.dev`.
- **Lokalnie:** `python3 -m http.server 8080 --directory flappy`
- **GitHub Pages:** po włączeniu Settings → Pages → Source: *GitHub Actions* każdy push do `master` zmieniający `flappy/` publikuje grę.
